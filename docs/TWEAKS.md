# Lite OS tweak list

> Generated from `tweaks/*.json` by `tests/Export-TweakDocs.ps1` - do not edit this file by hand.
> Change the JSON, then run `powershell -NoProfile -ExecutionPolicy Bypass -File tests\Export-TweakDocs.ps1`.

## How levels work

- **Balanced** applies every `balanced` tweak whose default is **yes**. It keeps Windows Defender, security updates,
  Microsoft Store, Xbox / Game Pass / Gaming Services, Game Bar, Edge + WebView2, Windows Hello, VBS/HVCI, TPM,
  BitLocker and kernel anti-cheat working.
- **Extreme** applies Balanced **plus** every `extreme` tweak whose default is **yes**. Read the descriptions: extreme
  tweaks trade security or compatibility for a little less background activity.
- Tweaks whose default is **no** are opt-in: they only run when you pick them in Custom mode or pass `-Include <id>`.
- **Risk** is our estimate of what can go wrong (`none`, `low`, `medium`, `high`). **Reboot** = needs a restart to take effect.
- Every change is recorded and can be undone with `Revert-LiteOS.ps1` (or menu option 5). Removed apps can be
  reinstalled from Microsoft Store or winget.

**77** tweaks in total: **43** in Balanced, **4** more in Extreme, **30** opt-in.
